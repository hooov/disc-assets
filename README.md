# sfx-fallback

Temporary copy of the dash sound library (`/obs/sfx/<folder>/`) while the Railway bucket is down (2026-10-22).
Widgets point their `soundBase` / `Sound_base` variable at `https://cdn.jsdelivr.net/gh/hooov/disc-assets@<commit>/<folder>/`.
Switch them back to `https://dash.suzy.gg/obs/sfx/<folder>/` once the bucket answers again.
